# Claude Telegram Bot — Render

Telegram-бот на aiogram 3 с Claude API, историей диалогов в SQL-базе, анализом документов и отправкой созданных файлов.

## Возможности
- Ответы Claude и помощь с кодом.
- История диалогов хранится в базе данных, `/reset` очищает историю.
- Приём TXT/MD/CSV/PDF/DOCX/XLSX и распространённых текстовых исходников.
- Создание текстовых файлов и ZIP-архивов; генерация DOCX/XLSX/PDF при запросе подходящего формата.
- FastAPI health endpoint для Render.

## Что требуется
- Telegram bot token от `@BotFather`.
- Anthropic API key из Anthropic Console и доступ к выбранной модели.
- Аккаунт Render и репозиторий GitHub.

## Развёртывание на Render
1. Загрузите содержимое проекта в новый GitHub-репозиторий. Не загружайте `.env` и никогда не коммитьте API-ключи.
2. В Render выберите **New → Blueprint**, подключите репозиторий и примените `render.yaml`.
3. В Environment Variables сервиса задайте:
   - `TELEGRAM_BOT_TOKEN`
   - `ANTHROPIC_API_KEY`
4. Проверьте `ANTHROPIC_MODEL`: значение по умолчанию — `claude-sonnet-4-5`. Если модель недоступна вашему аккаунту, замените на доступный model ID из актуальной документации Anthropic.
5. Дождитесь успешного деплоя. Откройте `/health` на URL сервиса; статус должен быть `ok`.
6. Откройте своего бота в Telegram и отправьте `/start`.

Blueprint включает PostgreSQL. Обратите внимание: Render-планы и цены могут меняться; выберите доступный план в интерфейсе, если план из YAML недоступен вашему аккаунту.

## Локальный запуск
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните значения в .env; переменные окружения должны быть загружены оболочкой
uvicorn app.main:app --reload --port 10000
```

Приложение читает переменные окружения процесса. Для локального `.env` установите `python-dotenv` или экспортируйте переменные перед запуском.

## Важно
- Не отправляйте ключи API в чат и не вставляйте их в исходники.
- Не публикуйте токен Telegram или `DATABASE_URL`.
- Не добавляйте бота в публичные группы с чувствительными данными без понимания последствий.
- Это стартовый проект. Перед публичным использованием добавьте rate limiting, ограничение расходов, резервное копирование БД и более строгую авторизацию/мониторинг.
- Входные файлы обрабатываются в памяти; содержимое документов передаётся в Claude API для ответа на ваш запрос.
